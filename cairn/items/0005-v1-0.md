## Ships

No new surface. The language reference and tutorial are complete, the store format is versioned, oath hashes are pinned by test, install is one command on macOS and Linux, and breaking any of that is a bug.

## Done when

- [ ] `cargo install oath-lang` and prebuilt binaries for macOS (arm64, x86_64) and Linux (x86_64)
- [ ] the reference documents every construct; the tutorial takes a stranger from install to importing a promise by hash
- [ ] golden hashes for the examples are pinned and CI fails if canonicalisation changes them
- [ ] three programs written by someone other than the author ran without filing a p0 bug

## Explicitly not in this milestone

- any new language feature; those go to `later`
- multi-party oaths; that is the v1.1 headline
