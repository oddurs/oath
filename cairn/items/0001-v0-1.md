## Ships

`oath run hello.oath` runs a pure program. `oath swear hello.oath` checks every keeper against its oath's examples, records the verdict in a store keyed by the oath's hash, and prints it. Every call site resolves through the oath to a sworn keeper. Editing an oath un-swears its keepers, visibly. That last line is the idea, and it is in v0.1 so a stranger feels it on day one.

## Done when

- [ ] a stranger can build from source on macOS or Linux, write a 20-line program with one oath and two keepers, swear it, run it, change an example, and watch the keepers become unsworn
- [ ] `scripts/task check` is green in CI on both platforms
- [ ] the README shows the whole loop

## Explicitly not in this milestone

- laws (properties); only examples are checked
- effects of any kind, including mutation
- a static type checker; the signature is a runtime contract at the oath boundary
- strings, user-defined types, a prelude
