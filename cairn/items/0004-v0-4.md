## Ships

Programs span files. `use ./lib.oath` imports by path; `use sort = oath:<hash>` imports one promise by its hash and never mentions its name. Renaming an oath breaks no importer. An imported oath with no sworn keeper is a hole, and `Keep` fires for it like any other. `oath ls` browses the store.

## Done when

- [ ] file B imports A's oath by hash, A's oath is renamed, B runs unchanged with no re-swearing
- [ ] editing an imported file's examples is reported to the importer as an oath change
- [ ] a shared promise with no body is filled through the command source and stored under the imported hash

## Explicitly not in this milestone

- a registry or any network fetch; `oath pack` is a file you hand to someone
- roles, choreographies, transports of any kind
