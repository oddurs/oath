## Ships

A hole is an oath with no keeper, and now reaching one at runtime fires the `Keep` effect instead of failing. Three keeper sources ship: pause into a REPL, search the store for a keeper of an equivalent oath, and pipe the oath to an external command and swear whatever comes back in a sandbox. When keepers from different sources disagree, the differential check says where.

## Done when

- [ ] `oath run` on a program with a hole keeper reaches it, pauses, accepts a body, swears it, and continues
- [ ] a shell script standing in for a model can fill a hole and its keeper is adopted only if sworn
- [ ] an unsworn proposal from the command source leaves no trace in the world or the store

## Explicitly not in this milestone

- expression-level holes (`?` inside a body); those need a type checker and live in `later`
- a first-party hosted model integration; the command source is the contract
- an editor or LSP
